# Transport multiple-scattering check results (V3-003A)

`mcs_checks.json` is the output of `validation/scripts/transport/mcs_checks.py`. It is
generated by the orchestrator at a clean committed SHA (`analysis_code_sha` and
`analysis_code_dirty` are recorded from `git`), with

    uv run python validation/scripts/transport/mcs_checks.py \
        --output validation/results/transport/mcs_checks.json --code-sha $(git rev-parse HEAD)

The script needs the hash-verified LaTeX source of Gottschalk, arXiv:0908.1413, in the git-ignored
`.ionmc-cache/reference/<sha256>` (sha256 `67fb1478...`, recorded in the file) and fails closed
(non-zero exit, no output) if it is missing or wrongly hashed, or if `--code-sha` differs from HEAD.

Contents (aggregates only; no table rows of the paper): U4 deviations of the quadrature of the
engine's `T_dM` along the CSDA path (158.6 MeV, Be/Al/Cu/Pb at x/R1 0.01, 0.1, 0.5, 0.9) from
`theta_Hanson (1 + dM %/100)`, our `rho R1` against the paper's; deviations of `X_S` from the
paper's table `tbl:LS`; the full U5 table (water, 150 MeV: relative deviation of the stepped
variance sum from the quadrature for steps 0.01 to 5 mm at x/R1 0.05 to 0.9) with the per-step
Highland negative control; a generalised-Highland cross-check for water.

Evidence status: U4, U4b and the `X_S` comparison are **source-model reproduction (Gottschalk 2010
formulae and tables; not independent)**: the reference is the paper's own table and formulae, and U4b is
implied by U4 with the paper's dM % column. U5 is deterministic self-consistency; the Highland
cross-check is a related model. The only independent scattering qualification is T15 (independent Monte
Carlo comparison, pending). Not a clinical claim. The U4 venue is local validation (LV): the source is not
in Git, so the corresponding tests skip in CI.
